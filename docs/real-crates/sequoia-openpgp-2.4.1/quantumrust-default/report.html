A 0.00 does not mean safe. A quantum-resistant primitive (Tier 3) scores a true zero because it needs no quantum migration — it is still cryptography, and it is still in the inventory above.

Scores compare only within a tier. A Tier 2 row can score higher than a Tier 1 row and still rank below it: the tier is the standard's deadline, and reach decides only which call in a tier to migrate first.

A → arrow under a call site is trait resolution. The caller wrote a trait path; the compiler resolves it to a concrete impl, and that is what the algorithm attribution uses. A → dyn, unresolved cannot be resolved statically — dynamic dispatch has no single target, which is the case the LLVM layer's vtable node exists for.

Rows marked upper bound were not resolved. The tool could not name the algorithm, so its tier is the ceiling of what its class could be. The rank is a bound, not a measurement, and the panel never names one as most severe.

Taint chains are collapsed. Click one to see the data-flow path from the key's construction to the operation that consumes it — the provenance behind the finding, and the thing that makes it checkable without re-running the tool.

Blast and Scope are different questions and use different edges. Blast is call-graph reach and drives the ranking; Scope is the taint-reachable subset and estimates what a migration must touch. Call-graph imprecision inflates the first without inflating the second, which is why they are kept apart. A dash means the estimate was not requested.

The analysis is crate-local. Cryptography reached only through a dependency's internals is not visible here; run with --manifest-assets to list declared crypto crates no call site reached.

Nothing here certifies compliance. Findings are reported against a named profile; compliance is the migration that follows discovery.
